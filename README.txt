Duncan Appalachian Sorting Table

Upload index.html and the assets folder together to your web host. Use HTTPS for the AR experience. The USDZ model is included in assets/duncan-table.usdz.

The QR code points to the currently hosted ChatGPT Site. If hosting at a new address, replace assets/site-qr.png with a QR code for your new URL.

AR links are enabled on iPhone and iPad, including Chrome on iOS. Actual AR launch depends on the device and browser. The model is a simplified design preview.
